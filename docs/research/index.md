# Research

The model on this site is derived from public evidence. These pages hold that
evidence and nothing else: every factual sentence has a numbered citation, and
[Sources and evidence](/research/sources) shows the verbatim sentence behind
each number. Where a page draws a conclusion for the model it says so under a
**Model reading** heading.

| Page | What it answers |
| --- | --- |
| [The Amazon logistics network](/research/amazon-logistics-network) | Which buildings and lanes the network has, how fast each part changes, regionalization, and the published split between the promise and order assignment. |
| [SP-API surface map](/research/sp-api-surface-map) | What the Selling Partner API and Amazon Shipping API actually expose about nodes, declared capability, purchase orders and promises, mapped to this model. Includes a correction to an earlier fleet finding about declared capability. |
| [Other benchmarks](/research/benchmarks) | Google Merchant Center, Walmart Marketplace, Shopify, and Oracle, Manhattan and IBM order promising. |
| [Sources and evidence](/research/sources) | All 31 sources with their supporting quotes. |

The warehouse-systems side is not researched here; it is read from the fleet's
repositories on `origin/develop` and cited by path on
[WMS/WES Integration](/integration).
