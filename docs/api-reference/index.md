# API Reference

Every page in this section is **generated**, except the
`warehouse-ops-agent` page and the short intro on each async page:

- **REST** pages are generated by
  [`docusaurus-plugin-openapi-docs`](https://github.com/PaloAltoNetworks/docusaurus-openapi-docs)
  from each context's own `apis/openapi.yaml`. That is the same spec the
  service ships and lints in its own CI. Seven contexts also ship an
  `apis/openapi-reports.yaml` for their separate `*-reports` binary
  (order-management, wes-work-planning, fulfillment-execution,
  workforce-management, facility-layout, process-path-management and
  labor-performance); each gets its own **Reports REST** section. Regenerate
  with `npm run clean-api-docs:all` then `npm run gen-api-docs:all`.
- **Async** pages embed static HTML generated by the official
  [AsyncAPI Generator](https://github.com/asyncapi/generator)
  (`@asyncapi/html-template`) from each context's own
  `apis/asyncapi.yaml`. Regenerate with `npm run gen-async-docs:all`.

Both spec sets are copied from each context repository's `develop` branch
into this repository's `apis/<context>/` directory. The
[README](https://github.com/IQVO/warehouse-docs#readme) describes the sync
procedure. Fix a spec in its owning repository and re-sync. Never edit the
copy here.

Every Kafka message on every channel below is a CloudEvents 1.0 event in
structured content mode. See the
[Event Standard](/strategic-design/event-standard-cloudevents). REST and MCP
surfaces are unauthenticated fleet-wide.

`openapi.yaml`. Async channels are the `channels` in its `asyncapi.yaml`,
with each channel's message count. **Pub** means the context owns and writes
the topic. **Sub** means it reads another context's topic.

## warehouse-ops-agent

`warehouse-ops-agent` has no `apis/openapi.yaml` and no `apis/asyncapi.yaml`.
It produces and consumes no Kafka topics, and calls the other contexts over
REST and MCP as a Customer. Its own REST and MCP surface is documented in
prose. See
[warehouse-ops-agent's API surface](/api-reference/warehouse-ops-agent).
