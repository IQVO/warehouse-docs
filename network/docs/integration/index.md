# WMS/WES Integration

The warehouse-systems fleet is a **vendor** of the network: its fulfillment
centres, cross-docks and returns centres become vendor nodes, its CPTs become
the network's pickup cutoffs, and its `network-fulfillment` context is the
only thing that talks to the network.
